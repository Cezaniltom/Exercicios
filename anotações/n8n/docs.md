Opção 1: Geração Automática por Inteligência Artificial (JSON → Texto Humano)
Esta é a opção mais amigável e rápida se o fluxo for muito técnico e complexo.
• Como funciona: Você exporta o código JSON do fluxo do n8n e o processa através de uma IA (como ChatGPT ou Claude) utilizando um template oficial de auto-documentação do n8n.
• O que o cliente recebe: Um texto em linguagem simples e comercial, dividido em:
	• Gatilho: O que inicia o processo (Ex: "Quando um formulário é preenchido").
	• Etapas: O que acontece com o dado (Ex: "Valida o e-mail" → "Cria o cliente no CRM").
	• Resultado: Onde o processo termina (Ex: "Envia mensagem de boas-vindas no WhatsApp").
• Ideal para: Entregar relatórios rápidos de consulta sem precisar digitar uma única linha de manual.
Opção 2: Guias Visuais Passo a Passo (Scribe / Tango)
Ideal se a automação exigir que o cliente final interaja com alguma tela ou faça alguma configuração simples de tempos em tempos.
• Como funciona: Utilizando as ferramentas Scribe ou Tango, você executa o fluxo uma vez no navegador. A extensão captura seus cliques e gera um manual visual automaticamente.
• O que o cliente recebe: Uma página web interativa com prints recortados exatamente no local do clique, acompanhados de instruções curtas (Ex: "Passo 1: Clique no botão Ativar. Passo 2: Verifique o histórico de execuções").
• Ideal para: Manuais de treinamento e guias de resolução de problemas simples (troubleshooting).
Opção 3: Central de Consultas no Notion (Manual Estruturado)
A melhor opção se você deseja centralizar todos os fluxos do cliente em um único portal profissional.
• Como funciona: Você cria uma página centralizada no Notion utilizando tabelas e elementos visuais simples.
• O que o cliente recebe: Um painel limpo contendo:
	• Diagrama Macro: Um print limpo do fluxo ou desenho feito no Miro.
	• Tabela de Regras: Uma matriz simples explicando os caminhos (Ex: "Se o cliente for VIP → Envia para o vendedor X").
	• Status de Credenciais: Uma lista com as ferramentas integradas e responsáveis.
• Ideal para: Grandes projetos onde o cliente precisa consultar regras de negócio com frequência.
